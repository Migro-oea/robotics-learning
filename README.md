# 🤖 MIGRO

The main project driving this repository is **MIGRO — Machine Intelligence for Generative Robotic Operations**.

MIGRO is a continuously evolving robotics software project designed to apply the concepts I learn throughout this journey.

The project is being developed primarily through simulation, allowing me to progressively explore:

```text
ROS 2
  ↓

Robot Control

  ↓

  ↓
```

Instead of building one large system immediately, MIGRO evolves incrementally as my engineering knowledge develops.
